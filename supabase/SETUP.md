# AI 서버 설정 안내 (v80.0) — 마스터가 Supabase 대시보드에서 할 일

앱은 이제 AI 키를 **Supabase 서버에만** 둡니다. 태블릿·선생님 PC 어디에도 키가 없습니다.
아래를 순서대로 하면 됩니다. 서버를 다 만들기 전에는 앱이 **예전 방식(기기 키)으로 그대로 돌아가므로** 급하게 할 필요는 없습니다.

| 파일 | 어디에 쓰나 |
|---|---|
| `supabase/sql/ai_usage.sql` | 1단계 — SQL Editor 에 붙여 넣기 |
| `supabase/functions/ai/index.ts` | 2단계 — 함수 편집기에 붙여 넣기 |

> 대시보드 편집기에는 **버전 기록이 없습니다.** 코드를 고칠 땐 이 저장소 파일을 고치고 다시 붙여 넣으세요. 이 파일들이 원본입니다.

---

## 0. 준비물 3가지

**① Gemini 유료 키 (채점용)**
- Google AI Studio에서 **새 프로젝트를 만들어** 그 프로젝트에 결제 계정을 연결하고, 거기서 키를 만드세요.
- ⚠️ **예전 무료 키가 들어 있는 프로젝트에 결제를 켜지 마세요.** 결제는 '프로젝트' 단위라 그 옛 키도 그 순간 유료가 됩니다.
  그 옛 키는 v79.0 때 앱의 공유 저장소(누구나 읽을 수 있음)에 올라갔을 수 있습니다.

**② Anthropic 키 (문제 출제용, Claude Opus 5)**
- platform.claude.com 콘솔 → API Keys 에서 만듭니다.
- **먼저 Settings → Billing → Spend limits 에서 월 지출 한도를 거세요** (예: 첫 달 $50). 넘으면 요청이 멈춥니다.

**③ 출제 비밀번호**
- 전 학년 문제를 Opus로 만들 때 선생님이 입력하는 값입니다. **아무도 못 맞힐 긴 문장**(20자 이상)으로 정하세요.
- 이 비밀번호가 없으면 서버는 Opus를 쓰지 않습니다(학생 요청은 늘 Gemini).

## 1. 비용 기록 표 만들기

대시보드 → **SQL Editor** → `supabase/sql/ai_usage.sql` 내용을 **통째로** 붙여 넣고 **Run**.
여러 번 실행해도 안전합니다.

이 표는 서버만 읽고 씁니다. 앱(공개 키)으로는 볼 수 없어서 비용 기록이 밖으로 새지 않습니다.

## 2. 서버 함수 만들기

대시보드 → **Edge Functions** → **Deploy a new function** → **Via Editor**
- 이름: **`ai`** (정확히 이 이름 — 앱이 `/functions/v1/ai` 를 부릅니다)
- `supabase/functions/ai/index.ts` 내용을 통째로 붙여 넣고 **Deploy function** (10~30초)

## 3. JWT 검증 끄기 ⚠️

이 함수는 **JWT 검증을 꺼야** 합니다. 앱은 공개 키(`sb_publishable_…`)만 보내는데, 공개 키는 JWT가 아니라서
검증이 켜져 있으면 모든 요청이 **401**로 막힙니다. (대신 함수 코드가 공개 키를 직접 확인합니다.)

함수 상세 화면의 설정에서 JWT 검증 스위치를 찾아 끄세요. 공식 문서에 대시보드의 정확한 이름이 나와 있지 않아서,
화면을 캡처해 주시면 같이 찾겠습니다.

## 4. 비밀값 넣기

대시보드 → **Edge Functions → Secrets** (Edge Function Secrets) 에서 Key / Value 를 넣고 저장.

| 이름 | 값 | 필수 |
|---|---|---|
| `GEMINI_API_KEY` | ① Gemini 유료 키 | ✅ |
| `ANTHROPIC_API_KEY` | ② Anthropic 키 (`sk-ant-…`) | ✅ |
| `DD_GEN_TOKEN` | ③ 출제 비밀번호 | ✅ |
| `DD_DAILY_BUDGET_USD` | 학생 사용 하루 예산(달러). 기본 5 | 선택 |
| `DD_GEN_DAILY_BUDGET_USD` | 문제 만들기 하루 예산(달러). 기본 30 | 선택 |
| `DD_STUDENT_DAILY_CALLS` | 학생 1명 하루 AI 호출 수. 기본 300 | 선택 |
| `DD_EFFORT_QUIZ` / `DD_EFFORT_VERIFY` | Opus 생각 깊이 `low`·`medium`·`high`. 기본 high | 선택 |

하루 예산에 닿으면 그날은 서버가 멈추고 다음 날(한국 시간) 다시 열립니다.
문제 만들기를 빨리 끝내고 싶으면 `DD_GEN_DAILY_BUDGET_USD` 를 잠깐 올리세요.

## 5. 앱에서 확인

선생님 화면 → **AI 연결** → 맨 아래 **AI 서버 · 문제 미리 만들기**
1. **출제 비밀번호** 입력 → **서버 연결 확인**
2. 이렇게 나오면 성공: **✅ 서버 연결 · 출제 비밀번호 맞음** (아래 기록 줄에 Gemini·Claude 키, 비용 기록 여부가 나옵니다)

한 번 연결에 성공한 기기는 그 뒤로 **절대 예전 방식(기기 키)으로 돌아가지 않습니다.**

## 6. 문제 미리 만들기

1. **시험 생성 (10세트)** → 끝나면 **1세트 평균 비용·시간**과 **전체 예상 비용·시간**이 나옵니다
2. 괜찮으면 **전체 이어서 만들기** — 멈췄다 다시 눌러도 이미 만든 건 건너뛰고 이어서 합니다
3. 이 탭은 **앞에 띄워 두고**, PC가 잠들지 않게 하세요. 전체는 수십 시간 걸릴 수 있어 며칠에 나눠 해도 됩니다

대상: 전 학년 소단원 1,062개 × 기본 2세트 + 초등 256개 × 응용 2세트 = **2,636세트**

## 7. 마무리

- 서버 연결이 확인되면 → 같은 칸의 **옛 공유 키 지우기** → 구글에서도 옛 무료 키를 삭제
- 비용은 **이번 달 AI 비용 보기**로 확인 (학생 1명당 비용도 나옵니다). 공식 단가로 계산한 추정치이고,
  실제 청구액은 구글·Anthropic 콘솔이 정답입니다.

## 알아 둘 것

- **무료 플랜 함수는 한 번에 150초 제한**입니다. Opus가 오래 생각하면 실패할 수 있어서 문제 만들기와 검산을 따로 부릅니다.
  시험 생성에서 실패가 많으면 `DD_EFFORT_QUIZ` 를 `medium` 으로 낮추세요.
- 공개 키는 앱 HTML 에 들어 있어 누구나 볼 수 있습니다. 그래서 진짜 방어는 **하루 예산 · 학생 호출 한도 · 출제 비밀번호 ·
  Anthropic 콘솔의 월 한도** 입니다.
- 고등 대수(40)·미적분(32) 소단원은 개념 카드가 없어서, 문제가 소단원 제목만 보고 만들어집니다.

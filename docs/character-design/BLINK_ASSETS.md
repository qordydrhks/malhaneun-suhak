# 눈 깜빡임 프레임 안내

이 문서는 Claude가 말하는 수학 앱의 눈 깜빡임을 연결할 때 사용할 원본·깜빡임 이미지의 위치와 규칙을 정리한다.

## 결론

- 부위별 눈 그림을 덧씌우지 않는다.
- 현재 앱에서 쓰는 표정 원본과, 그 그림에서 **주인공 캐릭터의 눈만 감긴 전체 그림**을 한 쌍으로 사용한다.
- 깜빡임 그림은 원본과 같은 폴더에 있고 파일명 끝에 `-blink`가 붙는다.
- 생성본 크기는 원본과 다를 수 있다. 이미 시험 적용한 Claude 쪽 합성 스크립트가 눈 위치를 찾아 처리하므로 임의로 리사이즈하지 않는다.
- 기존 `rig-parts/`의 부위 그림 100장은 삭제하지 않고 보관한다. 현재 깜빡임 연결에는 사용하지 않는다.

## 제작 요청문

ImageGen에는 각 원본을 편집 대상으로 주고 다음 의미를 유지해 요청했다.

> 이 그림에서 주인공 캐릭터의 두 눈만 자연스럽게 감겨. 나머지는 그대로 유지해. 원래 눈의 각도, 위치, 속눈썹 색과 스타일을 따르고, 두꺼운 별도 눈꺼풀을 붙이지 말아 줘. 눈썹·입·볼·눈물·몸·손발·포즈·숫자·장신구·효과·색·조명·투명 배경은 바꾸지 마.

아레시는 큰 숫자 2 캐릭터의 눈만 감기고, 머리 위 뚜삐의 눈과 표정은 원본 상태를 유지하도록 별도로 제한했다.

## 앱 연결 시 확인

- 원본과 `-blink` 파일을 상태별로 정확히 짝짓는다.
- 기본 순서는 `원본 → blink → 원본`이다.
- 한 번 감는 시간은 약 0.13초를 기준으로 한다.
- 간격은 2.5~6초 사이에서 무작위로 두고, 가끔 두 번 연속 깜빡일 수 있다.
- `prefers-reduced-motion`에서는 자동 깜빡임을 끈다.
- 6개 상태에서 위치가 흔들리지 않는지 데스크톱과 모바일에서 확인한다.

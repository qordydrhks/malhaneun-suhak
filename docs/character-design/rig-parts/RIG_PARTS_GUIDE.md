# 캐릭터 리깅 파츠 안내서

이 폴더에는 엑시·폴라·아레시·이리스·렘마의 눈 깜빡임, 시선 이동, 입 모양 교체, 팔·다리 손짓을 시험할 수 있는 **투명 PNG 리깅 파츠 1차 세트**가 있다. 아직 앱 코드에는 연결하지 않았다.

## 자산 성격

- 기존 표정 통그림은 팔·눈·입이 몸통과 겹쳐 있어 단순 잘라내기만 하면 가려진 면과 관절이 비게 된다.
- 그래서 이 세트는 기존 디자인을 참조해 각 부위를 **리깅용으로 다시 생성**한 자산이다. 기존 통그림을 픽셀 단위로 그대로 분해한 파일은 아니다.
- 각 PNG는 투명 배경이며, 가장자리의 발광과 그림자를 보존한 채 투명 여백을 줄여 저장했다.
- `structural-atlas.png`와 `facial-atlas.png`는 생성 원본 배열을 보존한 파일이다. 개별 파츠와 함께 보관한다.
- 앱에 연결할 때는 캐릭터별 기준 캔버스와 피벗 좌표를 한 번 더 맞춰야 한다. 현재 파츠는 크기가 내용에 맞게 잘려 있어 같은 좌표에 그대로 겹치면 자동 정렬되지 않는다.

## 공통 얼굴 파츠

모든 캐릭터 폴더에 아래 파일이 같은 이름으로 들어 있다.

| 파일 | 용도 |
|---|---|
| `eyes-sclera-open.png` | 눈동자가 없는 열린 눈의 흰자와 속눈썹 |
| `irises-center.png` | 정면을 보는 홍채·동공 한 쌍 |
| `irises-up-left.png` | 위·왼쪽을 보는 홍채·동공 한 쌍 |
| `eyelids-half.png` | 반쯤 감은 눈 한 쌍 |
| `eyelids-closed.png` | 완전히 감은 눈 한 쌍 |
| `eyebrows-neutral.png` | 기본 눈썹 한 쌍 |
| `mouth-o.png` | 작은 O형 입: 놀람 또는 말하기 중간 프레임 |
| `mouth-smile-open.png` | 크게 웃는 열린 입: 칭찬·기쁨 또는 말하기 프레임 |
| `mouth-frown.png` | 찡그린 입: 짧은 아쉬움·재도전 |

### 권장 얼굴 레이어 순서

1. 숫자 몸통
2. `eyes-sclera-open.png`
3. `irises-center.png` 또는 `irises-up-left.png`
4. 눈꺼풀 또는 눈 감김 파츠
5. `eyebrows-neutral.png`
6. 입 파츠 하나

반쯤 감은 눈과 완전히 감은 눈은 열린 눈 위에 무조건 덧씌우기보다, 캐릭터별 배치를 확인해 **열린 눈 세트와 교체**하는 방식이 가장 안전하다.

### 권장 깜빡임 순서

`열린 눈 → 반쯤 감은 눈 → 감은 눈 → 반쯤 감은 눈 → 열린 눈`

- 한 번의 깜빡임은 약 140~220ms로 짧게 둔다.
- 평상시 간격은 3~7초 사이에서 조금씩 바꾸면 기계적인 반복이 줄어든다.
- 경청·생각 상태에서는 시선 파츠를 먼저 바꾸고, 깜빡임 뒤에도 그 시선을 유지한다.
- 모션 감소 설정에서는 깜빡임을 끄고 상태별 정지 눈을 사용한다.

### 입 모양 사용 예

- 대기·경청: 상황에 맞는 통그림 또는 입 파츠를 숨긴 안정된 얼굴
- 짧은 말하기: `mouth-o.png ↔ mouth-smile-open.png`를 음성 크기에 맞춰 느리게 교체
- 칭찬: `mouth-smile-open.png`
- 재도전: `mouth-frown.png`를 2초 안쪽으로 보여 준 뒤 중립 상태로 복귀

현재 입 파츠는 표정용 3종이다. 정확한 립싱크가 필요하면 이후 `A/E/I/O/U`, 입 다문 모양, 이 보이는 모양을 별도 제작한다.

### 권장 몸 레이어와 피벗

- 기본 순서: 바닥 그림자 → 뒤쪽 팔다리 → 몸통 → 앞쪽 팔다리 → 얼굴 → 머리 위 상징·장신구 → 효과.
- 팔 피벗은 몸통과 닿는 어깨 쪽, 다리 피벗은 몸통과 닿는 위쪽에 둔다.
- 머리 위 숫자·뚜삐·장신구는 몸통과 다른 레이어로 두고 작은 상하 움직임만 사용한다.
- 각 파츠의 회전과 이동은 88px 모바일 표시 크기에서도 실루엣이 깨지지 않는 범위로 제한한다.

## 연결 전 확인 사항

- 캐릭터마다 기준 캔버스, 얼굴 중심, 발끝, 몸 중심, 관절 피벗 좌표를 기록한다.
- 열린 눈·반눈·감은 눈의 중심이 교체 중 흔들리지 않는지 확인한다.
- 입 세 종류의 중심과 턱 위치가 바뀌지 않는지 확인한다.
- 팔과 다리를 회전했을 때 몸통과의 연결부에 틈이나 겹침이 생기지 않는지 확인한다.
- 88px 모바일 표시, 고해상도 화면, 모션 감소 설정을 모두 확인한다.
- 기존 통그림 방식은 새 리깅이 검증될 때까지 유지한다.

# 실사용 흐름 점검 (2026-09-21, 배포 v86.6~86.7, 초5-1)

방법: 배포 사이트에서 `테스트학생`(초5, id s1789984665605)으로 직접 사용 — 글로 답하기.
1회차 4질문(맞음·틀림 2번·개념 보고 답함·69점) → 문제 풀기(1개 틀림 → 다시 풀기) → 시계 8일 뒤로(내 창만) 복습 카드
→ 2회차(힌트 2단계·다시 보기) → 3회차 계단 3칸(되묻기 1번) → 종합 문제 → 학부모 링크 → 선생님 학습 현황·학생 기록·AI 보고서.
⚠️ 테스트학생 기록이 서버에 남아 있음 — 다 쓰면 마스터가 학생 관리에서 삭제.

## 🔴 대전제(정확한 이해 확인 · 어른의 정확한 판단)를 흔드는 것

1. **회차가 학기 전체에 한 번에 걸린다** — 1회차를 한 번도 안 한 소단원도 2회차를 열면 곧바로 2회차 질문. 1회차 질문은 "다시 보기"(선택)로 밀리고
   안 해 본 질문인데 "다시 답하기"로 표시됨. 선생님 '회차 열기' 화면엔 학생별 진도가 없어 누가 1회차를 끝냈는지 모르고 올리게 됨.
2. **문제 '틀린 문제 다시 풀기'** = 같은 문제·같은 보기, 바로 위 해설에 정답이 있음 → 고르면 "🎉 3문제 모두 정답! 개념을 정확히 알고 있네요".
   기록도 최종 결과(3/3)로 남음("지난번 3문제 중 3문제 정답"). 처음 결과(2/3)가 사라짐.
3. **'완료' 기준이 느슨함** — 2회차 질문 4개 중 1개만 통과한 소단원이 선생님 격자(초록)·오늘 완료·학부모 리포트 "완료"·학생 홈 "2/29"에 완료로 잡힘.
4. **학부모 리포트에 어려워한 것이 없음** — 두 번 틀려 선생님 알림 간 개념, 개념 보고 답한 것, 문제 틀린 것이 안 보이고 잘한 것만.
   회차(1·2·3) 진행도 안 보임. "📈 점수가 오르고 있어요" 제목이 기록 없을 때도 뜸.
5. **AI 학습 보고서가 과장** — 한 번 공부(40분) 안의 다시 설명(15→100점)을 "20점 상승, 눈에 띄는 성장세"로, 개념 보고 답한 것을 "완벽히 이해",
   기본 문제를 "응용 문제 89%"로 씀. **'원장 선생님 코멘트'도 AI가 원장 말투로 써서** 그대로 보내질 수 있음.
6. **틀린 질문 '오늘은 다시 못 봄' 막기에 구멍** (ladder/ladder.js:343 은 목록·'이어서 설명하기'만 막음)
   - 결과 화면 **'다음 질문으로'** 버튼으로는 막힌 질문이 열리고 바로 통과됨(실제로 100점 통과 기록됨).
   - 막기 기록이 기기(localStorage)에만 → 다른 태블릿에선 바로 다시 가능.
   - '이어서 설명하기'가 첫 남은 질문만 고름 → 그게 막힌 질문이면 알림만 뜨고 다른 남은 질문(4번)으로 안 감.

## 🟠 흐름이 끊기거나 헷갈리는 곳

7. **'다음 질문으로'가 다음 번호가 아니라 첫 남은 질문으로** 감 (3번 통과 → 2번이 열림).
8. **소단원을 다 끝낸 뒤 갈 곳이 없음** — 홈 '이어서 공부하기' → 끝낸 소단원의 "이미 풀었어요" 화면 / '다른 개념 도전하기' → 같은 소단원 목록,
   이미 푼 "문제 풀기 →"가 또 뜸. 다음 소단원으로 가려면 '개념 목록'을 직접 찾아야 함.
9. **7일 복습** — 홈에 복습 개수 표시 없음('할 일 보기'를 눌러야 앎). 복습 카드를 누르면 모두 ✓인 질문 목록 + 이미 푼 '문제 풀기'만 → 무엇을 하라는지 안내 없음.
   복습으로 다시 답한 기록이 선생님 화면에서 그냥 "(1회차)"로 보여 복습인지 구분 안 됨. 회차 흐름과 7일 복습이 따로 놂.
10. **1회차 두 번 틀린 뒤 안내 "힌트를 보며 한 번 더 떠올려봐도 좋아요"** — 1회차엔 힌트 버튼이 없음.
11. **종합 문제(3회차) = 방금 계단에서 답한 식과 숫자까지 같음**(17-(6+3), 12÷2×3) → 종합 확인 힘이 약함.
12. **선생님 학생 기록에 질문 문장이 없음** — 같은 소단원 질문 4개가 같은 제목. 15점이 어느 질문인지 모름. 문제 풀기 결과도 이 목록에 없음.
13. 문제 만들기 20~30초 대기(뚜삐가 검산 중…) — 아이가 기다리기 김.
14. 1회차 질문 하나 막히면(개념 보고 답함) 그날 문제 풀기로 못 감 — 의도대로지만 "남은 질문 2개"에 오늘 못 여는 질문이 섞여 헷갈림.

새 앱 설계서 1판 — 말하는 수학 (우주 · 숫자 친구들)

2026-10-03 · 마스터와 정한 것(10/2~10/3) · 지금 앱 v92.2 는 그대로 두고 학생 화면부터 새로 · 지도 시안 따로(시안_지도.html)
대전제 ① 아이가 개념을 정확히 이해했는지 확인하고 이해하게 만든다 ② 어른이 그 이해도를 정확히 판단한다 — 게임 요소는 이 둘을 돕는 만큼만.

1. 그대로 쓰는 것 · 새로 만드는 것

  • 그대로: GitHub 같은 저장소(새 폴더) · Supabase(학생·기록) · AI 채점 서버 · 초4-2 질문·계단·그림 데이터
  • 기록 모양은 지금과 같게(질문 번호 · 회차 r1~r3) → 옛 선생님·학부모 화면에서도 보임
  • 새로: 학생 화면 전부 · Supabase 표 1~2개(코인·장식·메달)
  • 시범 = 초4-2, 학원 4학년에게 배정. 다른 학년은 옛 앱 그대로(옛 질문은 참고만)
  • 만드는 순서: 학생 화면 → 선생님 대시보드 → 학부모 리포트

2. 지도 (A안)

  • 은하 = 학기 하나(지도 한 장) · 별 = 대단원 · 행성 = 소단원(별을 도는 행성)
  • 회차마다 지도가 넓어짐: 1회차 행성 → 2회차 행성의 달 → 3회차 행성 속(핵)
  • 선행: 선생님이 연 과정마다 은하 따로, 위에서 바꾸기 · 등급도 은하마다
  • 홈 = 지도 + 등급 배지 + 큰 단추 「오늘 할 곳」. 진도는 빛나는 행성으로 보임(글자 최소)

3. 질문 스테이지 (한 화면에 질문 하나)

  • 친구가 묻고 아이는 말(또는 글)로 답 · 합격 70점
  • 합격 → 점수 + 짚은 핵심 ✓ + 모범 답
  • 불합격 → 1·2·3회차 모두 계단 방식: 되묻기 → 짧은 설명 → 다시 묻기(숫자 바꾼 새 질문) → 그래도 못 하면 그날 잠금(내일 다시). 옛 「개념 다시 보기」 팝업은 버림
  • 시간 제한(질문당): 1회차 약 2분 · 2회차 3분 · 3회차 4분 · 계산·연습장이 필요한 1·2회차 질문 +1분 · 채점 시간 제외 · 시간 다 되면 떨어진 것과 같게
  • 소단원 끝 = 문제 풀기 스테이지(기본문제, 처음 결과만) → 원하면 응용 보너스 스테이지
  • 7일 복습 알림 = 힌트 보거나 한 번에 못 한 것만(한 번에 통과한 건 3회차에서 자연히 다시 봄)

  • 처음 통과만 셈(다시 풀어 올리기 불가) · 지금까지 푼 것의 누적 평균 → 첫 소단원부터 바로 등급, 계속 바뀜

5. 나의 기록

  • 배지·캐릭터 누르면 열림: 별자리 + "한 번에 21 · 힌트 후 6 · 아직 2"
  • 숫자 누르면 그 질문 목록 · 아직 n → 누르면 바로 다시 학습(오늘 떨어진 건 "내일 열려요")
  • 모범 답은 통과한 질문만 보임 · 다시 해도 이해 점수는 그대로(연습 기록만)

6. 코인 · 상점 · 친구

  • 코인 = 처음 통과할 때 · 등급은 살 수 없음(실력) / 장식은 코인(노력)
  • 상점: 크기·장식·배경·받침대·별자리 특징을 가진 펫(펫도 꾸미기) · 값에 따라 살 수 있는 것 제한
  • 숫자 친구 5명 그대로(고르기·반응·깜빡임·이야기) · 선생님 배정 문제 보상은 나중

8. 안내 (늘 띄우지 않기)

  • 처음 튜토리얼(친구가 3~4장, 건너뛰기·다시 보기) · 처음 겪는 순간 한 번 안내 · 눌러서 보기 · 홈 구석 「우주 안내서」
  • 점수 설명은 숫자 없이: "스스로 한 번에 답하면 빛이 크게 모여" · "힌트 봐도 안 하는 것보다 훨씬 많이 모여"

9. 선생님 · 학부모

  • 로그인 첫 화면 새 컨셉으로 · PIN·권한·학생 관리·도움 알림·회차 열기·AI 비용·비번 = 꼭
  • 대시보드: 설명 걷어내고 깔끔하게, 전체 이력 한꺼번에 안 보이게 · 이해 점수·내역 여기서
  • 학부모 리포트: 내용 보완 · 링크에 비밀 글자(토큰)
  • 나중 문제은행 · 문제 미리 만들기 · 편집기(보류 — 선생님이 질문·답 고치는 건 중요, 서버 저장으로 다시)
  • 버림 질문 목록 고르기 · 이의 제기 · 대화형 · 빈칸 · 질문 고르기 화면

10. 내용 작업 (Claude) — 마스터 검토는 줄인다

  • 1·2회차 157질문에 되묻기·짧은 설명·다시 묻기 새로 · 계산 필요 표시 · 용어 문제(초3~초4-2, 개념카드에서) · 연산 문제 만들기 규칙
  • 품질은 규칙 + 자동 검사 + AI 채점 시험으로: 다시 묻기 숫자 전부 검산 · 원래 질문과 숫자 다름 · 짧은 설명이 답을 통째로 주지 않음 · 모범/절반/틀린 답 시험 통과
  • 마스터는 🤔 표시한 것만 + 실제 사용 기록(통과율 낮은 질문)으로 고침

11. 남은 결정

  • 코인 이름(별가루 등) · 상품 목록과 값 · 연산 하루 상한
  • 친구끼리 서로 꾸민 캐릭터를 볼 수 있게 할지
  • 등급 기준 숫자(50·70·80·90)는 시범 기록으로 조정
  • 만들기 전에(GPT 검토 정리에서): 도중에 나갔을 때 이어하기 · 그날 잠금을 선생님이 풀 수 있게 할지 · 마이크가 안 될 때 글 입력으로 넘어가기

12. 만드는 차례

  1. 내용 보강(10번) — 초4-2
  2. 학생: 질문 스테이지를 대표 소단원 하나로 끝까지 먼저 시험 → 로그인 · 친구 고르기 · 지도 · 문제 스테이지
  3. 이해 점수 · 등급 · 나의 기록 · 메달
  4. 코인 · 상점 · 펫 (그림은 GPT)
  5. 용어 맞히기 → 스피드 연산
  6. 안내(튜토리얼 · 우주 안내서)
  7. 선생님 대시보드 → 학부모 리포트

# 질문 계단 (선생님처럼 묻기) — 작업 기록

> ⭐ 대전제 (저장소 CLAUDE.md 맨 위): ① 학생이 개념을 **정확히** 이해하는지 확인하고 이해하게 만든다
> ② 선생님·부모님이 아이의 이해도를 **정확히** 판단할 수 있게 한다. 계단의 모든 칸은 이 둘을 만족해야 한다.

## 왜 시작했나 (2026-09-15)
기존 질문(기본/깊이 + 유형별 회상·이유·예·조건·오류)은 칸을 따로따로 채워서
① 한 줄로 이어지지 않고 ② 같은 걸 두 번 묻고 ③ 한 흐름이 소단원 여러 개로 쪼개져 있었다.
마스터가 원하는 모양: "이등변삼각형이 뭐야? → 성질은? → 어떻게 증명해? → (그림 보고) 증명해 봐".
초3 대화형(CV_DATA)은 AI가 다음 질문을 즉석에서 골라 흐트러졌다 → 이번엔 **선생님이 순서를 설계**한다.

## 결정된 것
- 기존 질문은 **지우지 않는다.** 새 계단은 별도 표로 만들고, 시범 단원에서 확인한 뒤 대체 여부를 정한다.
- 개념 종류 7가지: 정의형 · 성질·증명형 · 공식 유도형 · 방법 선택형 · 전략형 · 그래프·관계형 · 개념 확장형.
- **고등은 소단원마다 계단 하나(7~8칸) + 중단원 끝 종합(전략) 계단.** 여러 소단원을 한 계단에 묶으면 얇아진다(견본 1 실패).
- 칸 하나 = **질문 · 통과 기준 · 되묻기 · 짧은 설명 · 다시 묻기** (+ 이름표: 뜻/성질/이유/함정/적용/연결/전략, 교재 쪽).
- 교재의 **개념 Q · 기본예제 · ADVICE** 를 뼈대로 쓴다. 쪽수는 PDF 실물로 확인.

## 질문 쓰는 규칙 (마스터 피드백 2026-09-15)
1. **질문 하나만 따로 떠도 뜻이 통하게.** 식·조건을 질문 안에 넣는다. ("방금 결과에서…" 금지)
2. **말로 답하기 좋게: 답은 한두 문장.** 유도 과정·긴 식을 소리 내어 읽게 하지 않는다. "어느 부분이 지워져?"처럼 아이디어를 묻는다.
3. **통과 기준 = 핵심 아이디어 2~3개.** 숫자·식 결과를 요구하지 않는다(계산은 문제 풀기에서).
   예) α²+β² → "근과 계수의 관계로 합·곱을 구하고, 곱셈 공식 변형으로 바꿔 계산한다"면 통과.
4. **옆 칸은 반드시 새로운 걸 묻는다.** (견본 2 이등변 ③ 방법 / ④ 직접 증명이 같은 걸 물어 지적받음)
5. **용어 유래·철학 질문은 한 문장으로 답이 떨어질 때만.** (견본 2 판별식 ③ "왜 중근이라 부를까" 지적받음)
6. 음성 인식이 수식을 자주 망가뜨린다 → 수식 그대로를 채점 기준으로 삼지 않는다.

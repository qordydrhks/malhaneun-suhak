# 질문 계단 쓰는 법 — 에이전트용 설명서

"말하는 수학"은 학생이 수학 개념을 **말로 설명**하면 AI 선생님 '뚜삐'가 듣고 판정하는 앱이다.
너는 소단원마다 **선생님이 차례로 묻는 질문 계단**을 쓴다. 코드는 건드리지 않는다.

## ⭐ 대전제 (모든 칸이 만족해야 한다)
1. 학생이 개념을 **정확히** 이해하는지 확인하고, 이해하게 만든다.
2. 선생님·부모님이 이 결과로 아이의 이해도를 **정확히** 판단할 수 있다.
→ 외워서 읊으면 통과되는 칸, 운으로 맞힐 수 있는 칸, 무엇을 모르는지 안 드러나는 칸은 실패다.

## 계단 모양
- 소단원 하나 = 계단 하나. 칸 수는 **소단원 크기에 맞춘다**:
  계산 유형 하나짜리(예 "√((−3)²)+… 계산하면?") 2~3칸 / 보통 개념 3~5칸 / 큰 개념 6~8칸.
- 칸은 쉬운 것 → 어려운 것 순서. 첫 칸은 뜻이나 방법 이름처럼 누구나 시작할 수 있게.
- 칸마다 이름표 하나: **뜻 · 성질 · 이유 · 방법 · 함정 · 적용 · 연결 · 전략**.
  한 계단에 뜻·성질만 몰리지 않게. 가능하면 **이유**나 **함정** 칸을 하나 이상.
- 교재의 **Q(질문) → 빠른 A / 친절한 A**, 예제, 주의 박스를 뼈대로 쓴다. 교재에 없는 내용·중3 범위 밖 내용 금지.

## 칸 하나에 들어갈 것
| 칸 | 규칙 |
|---|---|
| `q` 질문 | **질문 하나만 따로 떠도 뜻이 통하게.** 필요한 식·조건을 질문 안에 넣는다. "방금", "위에서", "그럼 셋을" 같은 앞 칸 의존 금지. 반말("~해 봐", "~일까?") |
| `ideas` 통과 아이디어 | **2~3개** (정말 한 가지뿐이면 1개). 전부 말하면 통과. 각 아이디어는 **학생이 한 문장으로 말할 수 있는 크기**. |
| 아이디어별 되묻기 | 그 아이디어를 빠뜨렸을 때 선생님이 하는 질문 한 문장. **정답을 말하지 말고 떠올리게.** "○○ 이면 어떻게 될까?" 꼴 |
| `teach` 짧은 설명 | 되묻기 뒤에도 못 맞히면 보여 줄 설명. **그 칸 내용만** 2~3문장. 예시 하나 넣으면 좋다 |
| `again` 다시 묻기 | 설명을 본 뒤 **같은 내용을 다른 말로** 묻는 질문 한 문장 |
| `fig` | 그림이 꼭 있어야 답할 수 있는 칸이면 true |
| `src` | 교재 쪽 (예 "23쪽") |
| `half` / `wrong` | 채점 시험용 학생 답(음성 인식처럼 구어체). half=아이디어 일부만 맞게, wrong=흔한 오개념 |

## 반드시 지킬 규칙 (마스터 피드백으로 정해진 것)
1. **답은 한두 문장.** 긴 식이나 기호를 소리 내어 읽어야 하는 질문 금지. 유도 과정 전체를 말하게 하지 말고 **핵심 아이디어**를 묻는다.
   ✗ "(√a)² 이 a 가 되는 과정을 식으로 보여 줘" ✓ "√a 를 제곱하면 왜 a 가 될까? 제곱근의 뜻으로 말해 봐"
2. **통과 기준에 숫자 결과를 넣지 않는다.** 계산은 기본문제에서 확인한다. 방법·이유를 말하면 통과.
   ✗ "답은 5" ✓ "근호 안을 제곱수로 만들어 근호를 없앤다"
3. **옆 칸은 반드시 새로운 걸 묻는다.** 같은 내용을 말만 바꿔 두 번 묻지 않는다(방법을 묻고 곧바로 "직접 해 봐"도 같은 것).
4. **예/아니요만으로 맞힐 수 있는 아이디어 금지.** "할 수 있다" 같은 결론은 반드시 이유와 한 아이디어로 묶는다.
5. **용어 유래·철학 질문은 한 문장으로 답이 떨어질 때만.**
6. 음성 인식은 수식을 망가뜨린다(√→"루트", a²→"에이 제곱"). 아이디어는 **말로 표현 가능한 형태**로 쓴다.
7. 기존 질문(`high`, `qset`)은 재료로 참고하되, 규칙에 어긋나면 고쳐 쓴다. 기존 `keyPoints` 는 계단 어딘가에 모두 들어가야 한다.

## 좋은 예 (고1 판별식 견본에서)
```json
{ "kind":"함정",
  "q":"문제에 \"실근을 가진다\"라고 쓰여 있을 때와 \"서로 다른 두 실근을 가진다\"라고 쓰여 있을 때, 판별식 조건은 어떻게 달라?",
  "ideas":[["\"실근을 가진다\"는 중근도 포함하므로 D≥0","중근도 실근일까? 그렇다면 D=0 도 포함될까?"],
           ["\"서로 다른 두 실근\"은 D>0","두 근이 \"서로 달라야\" 한다면 D=0 인 경우는 어떻게 될까?"]],
  "teach":"중근은 \"서로 같은 두 실근\"이라 실근이야. 그래서 그냥 \"실근\"이면 D=0 도 들어가 D≥0, \"서로 다른\"이 붙으면 D=0 을 빼서 D>0.",
  "again":"\"이차방정식이 허근을 가지지 않는다\"는 판별식으로 어떻게 나타낼까?",
  "src":"145쪽", "half":"서로 다른 두 실근은 D가 0보다 커요", "wrong":"둘 다 D가 0보다 크면 돼요" }
```
전체 견본은 `작업도구/질문계단/ladder3_data.js` (필요한 부분만 grep 해서 봐라. 통째로 읽지 마라).

## 내놓을 파일 모양
`ladder_<조각>.json` — 배열, 항목 하나 = 소단원 하나.
```json
[{ "grade":"m3-1", "big":"1. 실수와 그 계산", "middle":"1. 제곱근과 실수", "small":"01. 제곱근이란 무엇일까?",
   "steps":[ { "kind":"뜻", "q":"...", "ideas":[["...","..."],["...","..."]], "teach":"...", "again":"...", "fig":false, "src":"19쪽", "half":"...", "wrong":"..." } ] }]
```
- `grade`·`big`·`middle`·`small` 은 받은 원천 파일에서 **한 글자도 바꾸지 말고** 복사.
- 수학은 반드시 맞아야 한다. 교재와 대조해라.
- 문장 부호: 곱하기 ×, 빼기 −, 루트 √, 제곱 ² 처럼 유니코드. JSON 문자열 안의 큰따옴표는 \" 로.

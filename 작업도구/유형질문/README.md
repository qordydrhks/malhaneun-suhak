# 유형별 질문(DD_QSET) 만들기 — 작업 도구

새 세션이 남은 학년(**중2 123 · 고1-2 133 = 256개**)을 이어서 만들 때 쓰는 것들이다.
**여기 있는 지침을 그대로 쓰면 앞 학년과 같은 품질이 나온다.** 새로 쓰지 말 것.

## 파일

| 파일 | 무엇 |
|---|---|
| `GUIDE.md` | **작성 지침 본체.** 에이전트에게 반드시 전부 읽히기 |
| `GUIDE_M12.md` | 중·고등 추가 지침(그림 없이 풀리게, π, 교육과정 범위) |
| `sample_e4.json` | 확정된 결과물 샘플(모양·말투 참고용) |
| `extract.py` | 초5·초6처럼 **큰따옴표** 표기 학년의 원천 데이터 추출 |
| `extract_e3.py` | 초3처럼 **작은따옴표** DD_CARDS/DD_KEYPOINTS 학년용(따옴표 두 종류 다 처리) |
| `extract_m12.py` | 중1-2처럼 **작은따옴표·중단원(middles)** 학년용 추출 |
| `check.py` / `check_m12.py` | 기계 점검(개수·big/small 일치·basedOn·중복·표기·그림참조) |
| `fix_unicode_frac.py` | 유니코드 분수기호(½ ⅓) → `1/2` 정리 + 대분수 띄어쓰기 |
| `fix_particle.py` | 대분수 조사 오타(`2과 1/2` → `2와 1/2`) |
| `build_block.py` / `insert_block.py` / `insert_m12.py` | dodream.html에 넣을 블록 만들기·삽입 |

경로는 이 폴더 기준으로 고치고, 만드는 JSON은 **저장소가 아니라 임시 폴더(scratchpad)** 에 두기.

## 순서

1. `extract*.py` 로 그 학년 원천 데이터(개념설명·핵심포인트·기존질문)를 뽑아 30개 안팎으로 조각낸다
2. 조각마다 Sonnet 에이전트 하나 — `GUIDE.md`(+중·고등이면 `GUIDE_M12.md`)를 **전부 읽히고** 시작
3. `check*.py` 로 기계 점검 → 걸린 것 수정
4. **내가 전 문항을 직접 읽는다.** 아래 "기계가 못 잡는 것" 참고
5. `build_block.py` → `insert_block.py` 로 dodream.html에 넣고, 브라우저로 실제 렌더 확인
6. `APP_VERSION` 올리고 커밋

## 🚨 에이전트가 매번 틀리는 것 (지침에 먼저 박을 것)

1. **`recall`을 개념마다 1개** — "기존 질문에 이미 있으니 뺀다"고 한다. 틀렸다.
   기존 질문은 유형 표시가 없어 기억/이해 구분(`QTYPE_LAYER`)에 안 쓰인다.
2. **`reason`도 개념마다 1개** — 역시 "이미 있다"며 뺀다.
   근거를 대면 고친다: 초5-1 기존 질문 119개 중 '왜'가 든 것은 1개, 초6-2는 132개 중 0개였다.
3. 중·고등은 **"그림을 보고 답하는 질문"** 이 되기 쉽다. 조건을 문장으로 다 쓰게 할 것.

목표 배분: **개념당 4개(recall 1 + reason 1 + example 1 + error 1)**,
reason이 진짜 "약속"뿐인 개념만 3개, 조건이 실제 있는 개념만 `condition`을 더해 5개.

## 기계가 못 잡는 것 — 사람이 읽어야 한다

- 유니코드 분수기호 `½ ⅓` (중1-2에서 31곳) → `fix_unicode_frac.py`
- 대분수 조사 `2과 1/2` (초5-1에서 5곳) → `fix_particle.py`
- 그 학년이 아직 안 배운 개념 (초6에 음수 `-4`가 나왔었다)
- "네/아니오"로 끝나는 이유 질문 → 끝에 "왜 그런지도 말해 봐" 붙이기
- 정의가 곧 답인 **약속 질문** ("직육면체의 면은 왜 직사각형일까?")
- 같은 개념 안에서 recall과 condition의 답이 같아지는 중복
- 질문은 "두 가지"인데 답은 셋인 식의 수 불일치
- **answerHint의 계산은 전부 검산할 것** (앞 학년 5개에서는 계산 오류 0건이었다)
- **`너가` → `네가`** (초3에서 17곳 나왔다. 에이전트가 반말을 쓰다가 자주 틀린다)

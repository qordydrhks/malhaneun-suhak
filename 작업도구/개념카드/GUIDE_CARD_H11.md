# 고1-1(공통수학1) 개념카드 작성 지침 (에이전트용) — 전부 읽고 시작할 것

앱 이름은 "말하는 수학". 학생이 수학 개념을 **자기 말로 설명**하면 AI가 듣고 채점한다.
제품 한 문장: **"풀 수 있는가가 아니라, 설명할 수 있는가."**

## 0. 가장 먼저 할 일 (순서를 지켜라)

1. 담당 원천 파일 `src_<조각>.json` 을 읽는다 — 담당 개념 목록(id·big·middle·small)이 들어 있다.
2. `img/<조각>/pNNN.png` 교재 이미지를 **전부** 읽는다. 스캔본이라 글자 추출이 안 되고 이미지로 봐야 한다.
   (파일명 NNN = **교재에 인쇄된 쪽번호**다. 그대로 `bookPage`에 쓰면 된다.)
3. 결과 JSON을 **먼저 저장한다.** 개념 몇 개씩 쓸 때마다 파일을 갱신해라.
4. **그 다음에** 자기 점검을 하고 고친다. (도중에 한도로 죽어도 결과가 남게 하려는 것이다.)

## 1. ⚠️ 앞 학년과 다른 점 — 말하기 질문도 네가 써야 한다

중3은 옛 말하기 질문이 있어서 그대로 옮겼지만, **고1-1은 앱에 아무것도 없다.**
그래서 개념카드에 더해 **말하기 질문 `low` 3개 · `high` 3개**를 네가 직접 써야 한다.

- `low` = **채워보기 수준.** 짧게 답할 수 있는 질문. 앞에 `①②③` 기호를 붙인다.
- `high` = **설명하기 수준.** "설명해 봐 / 말해 줘"로 끝나는 질문. 앞에 `①②③` 기호를 붙인다.
- 둘 다 그 개념 하나에 대한 질문이어야 하고, 서로 답이 겹치지 않게 각도를 달리한다.

예 (다항식의 정리):
```
low:  ["① 다항식을 정리하는 두 가지 방법은 무엇일까?",
       "② 내림차순은 차수를 어떤 순서로 쓰는 걸까?",
       "③ 특별한 말이 없으면 보통 어느 차순으로 정리할까?"]
high: ["① 내림차순과 오름차순이 각각 무엇인지 설명해 봐.",
       "② 다항식을 정리하면 무엇이 편해지는지 말해 줘.",
       "③ 여러 문자가 섞인 다항식에서 기준 문자를 정하는 이유를 설명해 봐."]
```

## 2. 결과물 형식

`cards_<조각>.json` 에 **배열** 하나로 저장한다. 원천 개념 순서 그대로, 하나도 빠뜨리지 말 것.

```json
[
 {
  "id": 1,
  "small": "01. 다항식에 관련된 여러 가지 용어",
  "low": ["① …", "② …", "③ …"],
  "high": ["① …", "② …", "③ …"],
  "hints": ["…", "…"],
  "concept": "…",
  "keyPoints": ["…", "…"],
  "basicProblem": { "stem":"…", "choices":["…","…","…","…"], "answer":2, "explain":"…" },
  "bookPage": "숨마쿰라우데 공통수학1 · 18쪽",
  "figNeeded": false,
  "figNote": ""
 }
]
```

- **`id`·`small`** — 원천의 값을 **그대로 복사**해라. 한 글자도 바꾸지 마라.
- **`low`/`high`** — 각 3개. 위 1장 참고.
- **`hints`** — **정확히 2개.** 학생이 막혔을 때 주는 힌트.
  🚨 **힌트가 정답을 그대로 말하면 안 된다.** "생각할 방향"만 준다.
- **`concept`** — 개념 설명 2~4문장. **교재 내용 기준**으로, 학생에게 말하듯 반말(`~야`, `~해`).
- **`keyPoints`** — **1~3개.** 이게 **채점 기준**이다. 평서문 `~다`로 끝낸다(마침표 없이).
  틀리면 학생이 맞는 답을 하고도 틀렸다고 채점되니 반드시 정확하게.
- **`basicProblem`** — 4지선다 1개. `answer`는 **0부터 세는 번호**.
  🚨 **정답 번호를 0~3에 골고루 흩어라.** 🚨 **계산을 반드시 검산할 것.**
- **`bookPage`** — `"숨마쿰라우데 공통수학1 · N쪽"`. N은 네가 읽은 이미지 파일명의 번호.
- **`figNeeded`/`figNote`** — 이 개념을 이해하려면 그림·그래프가 필요한가? true/false와 한 줄 설명.
  (지금은 그림을 만들지 않는다. 나중 작업을 위해 표시만 남기는 것이다.)

## 3. 🚨 수식 표기 규칙 (앱 표시기가 아는 것만)

- **역슬래시 금지.** LaTeX(`\frac`, `\sqrt`) 절대 쓰지 마. 마크다운(`**굵게**`, `$수식$`) 금지.
- 분수: `1/2`, `(a+b)/2`, `(-b±√(b²-4ac))/(2a)` — 여러 항이면 **괄호로 묶어라**.
- 근호: `√(b²-4ac)`, `√2` — 안이 두 글자 이상이면 **괄호**.
- 거듭제곱: `x²`, `x³`만 유니코드. 그 밖에는 `x^4`, `a^n`.
  🚨 **유니코드 위첨자 `⁴ ⁿ ⁻` 금지.** 🚨 **유니코드 분수 `½ ⅓` 금지** → `1/2`.
- 아래첨자: `x1`, `a2` (밑줄 `x_1` 금지).
- 허수단위는 `i`, 켤레복소수는 **`z의 켤레복소수`처럼 말로 쓴다**(위에 줄 긋는 기호는 표시가 안 된다).
- 순열·조합은 `nPr`, `nCr` 꼴로 쓴다(아래첨자 기호 금지). 계승은 `n!`.
- 행렬은 문장으로 풀어 써라. 예: "2×2 행렬 A의 (1,2)성분", "행렬 (a b / c d)"처럼
  괄호와 슬래시로 행을 구분해 표기한다.
- 기호는 유니코드 그대로: `≤ ≥ ≠ ± × ÷ √ ∴ ∵ →`
- 곱셈은 `×`. `*` 쓰지 마.
- 🚨 **`너가` 아니라 `네가`.**

## 4. 🚨 내용 규칙

1. **그림 없이 글자만 읽고도 답할 수 있어야 한다.**
   "아래 그림에서", "다음 그래프의" 같은 말을 쓰지 마라. 조건이 필요하면 **문장으로 다 써라.**
   - 나쁨: "다음 그래프에서 이차함수의 최솟값은?"
   - 좋음: "이차함수 y=x²-4x+7의 최솟값을 구하는 방법을 말해 봐."
2. **고1-1(공통수학1) 범위를 넘지 마라.**
   - 이 학기: 다항식, 방정식과 부등식(복소수 포함), 경우의 수(순열·조합), 행렬.
   - 앞 과정(중학 전 범위)은 당연히 OK.
   - 🚨 **쓰면 안 되는 것**: 도형의 방정식·집합과 명제·함수(유리·무리)는 **공통수학2**다.
     삼각함수·지수로그·수열·미적분·확률·통계도 안 된다.
     (단, 이차함수는 이 학기 범위에 있으니 써도 된다.)
3. **말투는 반말**(`~야`, `~해 봐`, `~일까?`). 고1이니 아기 같은 말투는 쓰지 마라.
4. 교재에 있는 내용으로 써라. 지어내지 마라. 교재와 다르면 교재가 맞다.
5. 개념 설명이 **소단원 이름에 대한 답**이 되게 써라.

## 5. 저장 후 자기 점검 (저장한 뒤에)

- [ ] 개념 개수가 원천과 같은가? id·small이 원천과 글자까지 같은가?
- [ ] `low` 3개 · `high` 3개인가? `①②③` 기호를 붙였는가? low와 high의 답이 겹치지 않는가?
- [ ] `hints` 2개인가? 힌트가 답을 그대로 말하지 않는가?
- [ ] `keyPoints` 1~3개이고 `~다`로 끝나는가(마침표 없이)?
- [ ] `answer`가 0~3이고 한 번호에 몰리지 않았는가? 정답이 정확히 하나인가? **계산을 다시 했는가?**
- [ ] 역슬래시 `\`, 유니코드 분수 `½`, 유니코드 위첨자 `⁴`, `너가`, 마크다운 `**`가 하나도 없는가?
- [ ] "그림", "그래프에서", "아래 도형" 같은 그림 의존 표현이 없는가?
- [ ] 공통수학2 내용(집합·명제·유리함수·무리함수·도형의 방정식)을 쓰지 않았는가?
- [ ] `bookPage` 쪽번호가 실제로 읽은 이미지 번호인가?

고쳤으면 **파일을 다시 저장**하라.

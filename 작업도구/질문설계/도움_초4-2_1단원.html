01. 분수의 덧셈 (1) — 분모가 같은 진분수

🌱 선수
분수 3/5에 대해 설명해 봐.
교재 3-1 160·162쪽
꼭 말할 핵심① 1을 똑같이 5로 나눈 것 중의 3개② 1/5이 3개
되묻기① 빠지면 전체를 어떻게 나눈 것 중의 몇이야?
② 빠지면 단위분수로 말하면 무엇이 몇 개야?
다시 묻기분수 4/7에 대해 설명해 봐.
모범 답: 1을 똑같이 7로 나눈 것 중의 4개예요. 1/7이 4개인 수예요.
핵심: 1을 똑같이 7로 나눈 것 중의 4개 · 1/7이 4개
🔑 키워드똑같이 나눈 것 중의단위분수가 몇 개
짧은 설명3/5은 전체를 똑같이 5로 나눈 것 중의 3이야. 1/5이 3개인 수야. 3학년 때 배운 거야.
긴 설명분수 3/5은 전체를 똑같이 5로 나눈 것 중의 3을 말해. 아래에 있는 5는 분모, 위에 있는 3은 분자라고 해. 1/5처럼 분자가 1인 분수를 단위분수라고 하는데, 3/5은 1/5이 3개인 수야. 3학년 때 배운 거야.

🔑 키워드분모는 그대로분자끼리 더하기
짧은 설명분모가 같은 분수의 덧셈은 분모는 그대로 쓰고, 분자끼리 더해.
긴 설명3/8은 1/8이 3개, 2/8는 1/8이 2개야. 더하면 1/8이 3 + 2 = 5개가 되니까 답은 5/8. 조각의 크기(분모)는 그대로이고 조각의 수(분자)만 늘어나. 그래서 분모가 같은 분수의 덧셈은 분모는 그대로 쓰고, 분자끼리 더해.

긴 설명2/7는 1/7이 2개, 3/7은 1/7이 3개야. 더하면 1/7이 5개가 되니까 답은 5/7. 분모 7은 조각의 크기라서 더해도 그대로야. 분모까지 더해 5/14로 쓰면 1/14 조각이 5개가 되는데, 그림처럼 1/14 조각은 1/7 조각보다 작아서 5/14는 5/7보다 훨씬 작아.

02. 분수의 덧셈 (2) — 대분수

1회차
2와 1/4 + 1과 2/4를 계산하는 과정을 말해 봐.
교재 4-2 10쪽
꼭 말할 핵심① 자연수끼리 더해 3② 분수끼리 더해 3/4 → 3과 3/4
되묻기① 빠지면 대분수는 어느 부분끼리 나누어 더해?
② 빠지면 두 결과를 합치면 얼마야?
다시 묻기1과 2/5 + 3과 1/5을 계산하는 과정을 말해 봐.
모범 답: 자연수끼리 1 + 3 = 4, 분수끼리 2/5 + 1/5 = 3/5 → 4와 3/5이에요.
핵심: 자연수끼리 더해 4 · 분수끼리 더해 3/5 → 4와 3/5
🔑 키워드자연수끼리분수끼리
짧은 설명받아올림이 없는 (대분수) + (대분수)는 자연수 부분끼리, 분수 부분끼리 더해.
긴 설명2와 1/4 + 1과 2/4에서 자연수끼리 2 + 1 = 3, 분수끼리 1/4 + 2/4 = 3/4이니까, 둘을 합하면 3과 3/4이야. 세로로 써서 자연수는 자연수끼리, 분수는 분수끼리 줄을 맞춰 더해도 돼.

모범 답: 11/8 = 1과 3/8이니까 1을 자연수로 올려 5와 3/8이에요.
핵심: 11/8 = 1과 3/8 · 1을 자연수로 올려 5와 3/8
🔑 키워드가분수 → 대분수1을 자연수로
짧은 설명분수 부분끼리 더한 결과가 가분수이면 대분수로 바꿔. 그때 생긴 1은 자연수 부분에 더해.
긴 설명1과 3/4 + 1과 2/4에서 자연수끼리 1 + 1 = 2, 분수끼리 3/4 + 2/4 = 5/4야. 5/4는 4/4와 1/4이고 4/4는 1이니까 5/4 = 1과 1/4. 그래서 2 + 1과 1/4 = 3과 1/4이 돼. 대분수를 가분수로 바꾸어 7/4 + 6/4 = 13/4 = 3과 1/4로 계산해도 돼.

짧은 설명대분수를 가분수로 바꾸어 분자끼리 더하고, 결과가 가분수이면 대분수로 바꿔.

교재 4-2 10·14쪽

되묻기① 빠지면 분수 부분끼리 먼저 더해 보면 어떻게 돼?
② 빠지면 그 결과를 자연수 부분에 더하면?

모범 답: 분수끼리 2/7 + 5/7 = 7/7 = 1이라서 4 + 1 = 5가 돼요.
핵심: 분수끼리 더하면 7/7 = 1 · 그래서 자연수 5
🔑 키워드분수 부분끼리 먼저분모와 분자가 같으면 1
짧은 설명분수 부분끼리 더한 값이 분모와 분자가 같은 분수이면 1이야. 그러면 답은 자연수가 돼.
긴 설명분수 부분 5/9와 4/9를 먼저 더해 보면 9/9야. 분모와 분자가 같은 분수는 1이니까(1 = 2/2 = 3/3 = … = 9/9) 분수 부분이 남지 않아. 그래서 자연수 2 + 1에 1을 더한 4가 답이고, 답은 자연수야.

핵심: 9/6는 가분수라 1을 자연수로 올려야 함 · 4와 3/6

짧은 설명분수 부분이 가분수이면 대분수로 바꿔서 1을 자연수 부분에 더해야 해. 답은 자연수와 진분수로 나타내.
긴 설명분수끼리 3/5 + 4/5 = 7/5인데, 7/5처럼 분자가 분모보다 큰 분수는 가분수야. 7/5은 5/5와 2/5로 나눌 수 있고 5/5는 1이니까 7/5 = 1과 2/5야. 이 1을 자연수 3에 더하면 답은 4와 2/5. 대분수의 분수 부분은 진분수여야 해.

03. 분수의 뺄셈 (1) — 진분수끼리, 1 − 진분수

1회차
5/7 − 2/7을 계산하는 과정을 말해 봐.

🔑 키워드분모는 그대로자연수끼리·분수끼리받아내림
짧은 설명분모가 같은 분수의 덧셈과 뺄셈은 분모는 그대로 쓰고 분자끼리 계산해. 대분수는 자연수끼리, 분수끼리 계산하고, 분수끼리 뺄 수 없으면 자연수에서 1만큼을 가분수로 바꿔.
긴 설명이 단원의 계산은 모두 같은 생각에서 나와. ① 분모가 같으면 조각의 크기가 같으니까 분모는 그대로, 분자끼리 더하거나 빼. ② 대분수는 자연수 부분끼리, 분수 부분끼리 계산해. ③ 더한 분수 부분이 가분수이면 대분수로 바꿔 1을 자연수로 올리고, 분수 부분끼리 뺄 수 없으면 자연수에서 1만큼을 가분수로 바꿔. 대분수를 가분수로 바꾸어 계산하는 방법도 있어.

## 세트 구조
- 행성(소단원) 하나 × 회차(1·2·3) × (mission 1세트 + hard mission 1세트) = **행성당 6세트**.
- 세트당 문제 수 = 앱 `M.count`: 1·2회차 = 데이터 `quiz` 값(대개 2) / 3회차 = 계단 칸 수(2~5).
- 회차가 오를수록 어렵게: 1회차 = 그 회차에 배운 뜻·성질을 두세 단계로 / 2회차 = 개념 하나를 비틀어 적용 / 3회차 = 계단에서 다룬 생각을 써야 풀림.

## 난이도 (2판 기준)
- **기본**: 그림만 보고 바로 답이 보이면 안 된다. **두세 단계**(디딤돌 발전 문제 수준).
- **응용**: **여러 성질을 이어야** 풀림(최상위 S 수준). 합과 차·이등변·정삼각형·네 각의 합 같은 앞 단원 지식과 잇기.
- **그 학년까지 배운 것만.** 엇각·동위각 등 중학교 내용 금지. 4-2 사각형이면 직선 180° · 삼각형 180° · 사각형 360° · 이등변·정삼각형 · 수직·평행 · 평행사변형·마름모 성질.
- 문제 안에 **지름길(우연히 같은 값)** 이 생기지 않게 — 중간 값이 답과 같으면 숫자를 바꾼다(2판에서 수직 두 쌍 문제가 늘 같은 값이 나와 버림).

## 보기 · 오답
- 정답은 정확히 하나. **오답 4개 = 아이들이 실제로 멈추는 자리**(중간 값 · 반대쪽 각 · 반으로 나눈 값 · 빠뜨린 변 · 꼬인 모양까지 센 것).
- 오답마다 `wrong` 에 **"이 답이 뜻하는 실수"**를 적는다 → 어른 기록에 어디서 멈췄는지 보임. 메모는 **실제로 그 계산을 하면 그 값이 나오는지** 직접 계산해서 확인.
- 정답 위치를 ①~⑤에 고르게.

## 그림
- 개념 질문 규칙 그대로: **조건만** 그린다(구하는 값은 ㉠·□), 답·풀이 금지, **재탕 금지**, 실제 길이·각대로, 고급스럽게.
- 각도는 그림 좌표로 다시 재서(`angle_at`) 문제의 수와 맞는지 assert. 점·선 개수 세기는 프로그램으로 센다(점 종이 후보 등).
- 크롬으로 실제 렌더해 글자 겹침·잘림·㉠ 위치를 눈으로 확인(쪽마다 PNG).
- 점이 변 위에 붙은 것처럼 보이면 각을 바꿔 떼어 놓는다.

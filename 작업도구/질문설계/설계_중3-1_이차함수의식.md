## 94. 꼭짓점 (225쪽)  핵심 A 꼴 · B 다른 한 점으로 a · C 꼭짓점이 원점/축 위
1회차
1. 꼭짓점의 좌표가 주어지면 이차함수의 식을 어떤 꼴로 놓아? [A] → y=a(x−p)²+q
2. 꼭짓점이 (3, −2)인 포물선은 식을 어떻게 놓아? [A] → y=a(x−3)²−2
3. 꼭짓점으로 y=a(x−p)²+q를 놓은 뒤에 a는 어떻게 구해? [B] → 다른 한 점 대입
2회차
4. 꼭짓점이 (−1, 4)이고 점 (1, 0)을 지나는 포물선의 식을 구하는 과정을 말해 봐. [A·B] → a=−1, y=−(x+1)²+4
5. 친구가 꼭짓점 (−2, 1)을 보고 y=a(x−2)²+1로 놓았어. 뭐가 틀렸어? [A] → (x+2)
6. 꼭짓점이 원점이면 식이 어떻게 간단해져? 꼭짓점이 (0, 3)이면? [C] → y=ax², y=ax²+3
7. 🖼 그래프에 꼭짓점 (1, 3)과 y축과 만나는 점 (0, 1)이 보여. 식을 구하는 과정을 말해 봐. [A·B] → a=−2
3회차 (유형 6-1)
8. 꼭짓점이 (2, 1)이고 점 (3, 3)을 지나는 포물선의 y절편은 어떤 차례로 구해? → a=2 → y절편 9

## 95. 축 (226쪽)  핵심 A 축=꼭짓점 x좌표 · B 미지수 a,q → 두 점 연립 · C 두 x절편 가운데가 축
1회차
1. 축의 방정식이 x=p로 주어지면 식을 어떤 꼴로 놓아? 왜? [A]
2. 축이 주어져서 y=a(x−p)²+q로 놓으면 모르는 수가 몇 개야? 그래서 점이 몇 개 필요해? [B] → 2개
2회차
3. 축이 x=1이고 두 점 (0, 1), (3, 7)을 지나는 포물선의 식을 구하는 과정을 말해 봐. [A·B] → a=2, q=−1
4. 꼭짓점이 주어질 때와 축이 주어질 때, 대입하는 점의 개수가 왜 달라? [B]
5. 포물선이 x축과 (1, 0), (5, 0)에서 만나면 축의 방정식은? 왜? [C] → x=3
3회차 (유형 6-3)
6. 축이 x=1이고 y절편이 3인 포물선이 두 점 (−1, 9), (4, k)를 지날 때, k는 어떤 차례로 구해? → a=2, q=1 → k=19

## 96. 세 점 (226쪽)  핵심 A 일반형 · B x좌표 0인 점 먼저 → c · C 연립
1회차
1. 꼭짓점도 축도 모르고 세 점만 주어지면 식을 어떤 꼴로 놓아? 왜? [A]
2. 세 점을 대입할 때 어떤 점부터 넣으면 편해? [B]
2회차
3. 세 점 (0, 2), (1, 3), (−1, 5)를 지나는 포물선의 식을 구하는 과정을 말해 봐. [A·B·C] → y=2x²−x+2
4. 어떤 조건이 주어지면 y=a(x−p)²+q로, 어떤 조건이면 y=ax²+bx+c로 식을 세워? [A]
3회차 (중단원 16·20)
5. 세 점 (0, 3), (1, 2), (2, 3)을 지나는 포물선의 꼭짓점은 어떤 차례로 구해? → y=(x−1)²+2 → (1, 2) / 지름길: (0,3)(2,3) → 축 x=1

## 97. x축과 두 점 (227쪽)  핵심 A a(x−α)(x−β) · B 한 점으로 a · C x절편 = 방정식의 해
1회차
1. 포물선이 x축과 두 점 (α, 0), (β, 0)에서 만나면 식을 어떤 꼴로 놓아? [A]
2. y=a(x−α)(x−β)로 놓은 뒤에는 무엇을 더 구하면 돼? [B]
2회차
3. 함수에서의 x절편은 방정식에서 뭐라고 할 수 있지? [C]
4. x축과 (−1, 0), (3, 0)에서 만나고 점 (1, −8)을 지나는 포물선의 식을 구하는 과정을 말해 봐. [A·B] → a=2
5. x축과 (−1, 0), (3, 0)에서 만나고 점 (1, −8)을 지나는 포물선의 식을 y=ax²+bx+c로 놓고 구해도 돼? 어느 쪽이 더 편해? [A]
3회차
6. 🖼 그래프가 x축과 −2, 1에서 만나고 y절편이 −4일 때, y=ax²+bx+c에서 a−b+c는 어떤 차례로 구해? (유형 7-3) → a=2 → f(−1)=−4

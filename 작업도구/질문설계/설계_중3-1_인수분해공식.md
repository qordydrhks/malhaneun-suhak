## 42. a²+2ab+b², a²−2ab+b² (100쪽)
핵심 A 곱셈 공식 거꾸로 · B 양 끝이 제곱, 가운데 항이 두 수 곱의 2배(부호는 가운데 항) · C 공통인수 먼저
막힘: 가운데 2배 확인 안 함 · 부호 · 공통인수 안 묶음
1회차
1. x²+10x+25를 인수분해하는 과정을 말해 봐. [A·B] → 25=5², 10x=2×x×5 → (x+5)²
2. 4x²−4x+1은? [B] → (2x)², 1², −4x=−2×2x×1 → (2x−1)²
3. a²+2ab+b²과 a²−2ab+b²은 인수분해한 결과가 어떻게 달라? [B] → 가운데 항 부호대로 (a+b)², (a−b)²
4. 🖼 a² 정사각형 1개, ab 직사각형 2개, b² 정사각형 1개를 모두 붙이면 어떤 도형이 돼? [A] → 한 변이 a+b인 정사각형
2회차
5. 3x²−18x+27을 인수분해할 때 가장 먼저 뭘 해? [C] → 공통인수 3 → 3(x−3)²
6. 친구가 x²+6x+4를 (x+2)²으로 인수분해했어. 뭐가 틀렸어? [B] → (x+2)²의 가운데 항은 4x, 6x라 완전제곱식 아님
3회차 (유형 6-1)
7. 넓이가 4x²+36x+81인 정사각형의 한 변의 길이는 어떤 차례로 구해? → (2x)², 9², 36x=2×2x×9 확인 → (2x+9)² → 2x+9

## 43. 완전제곱식이 되는 조건 (101쪽)
핵심 A 완전제곱식의 뜻 · B x²+ax+b는 b=(a/2)² · C x² 계수가 1이 아니면 양 끝 제곱 꼴 보고 가운데 확인
1회차
1. 완전제곱식이 뭐야? [A] → 다항식의 제곱이나 거기에 상수를 곱한 식
2. x²+ax+b가 완전제곱식이 되려면 b가 어때야 해? [B] → x의 계수의 절반의 제곱
3. x²+8x+□가 완전제곱식이 되려면 □는? 어떻게 구했어? [B] → 4²=16
2회차
4. 9x²+□x+4가 완전제곱식이 되려면 □는 몇이야? [C] → ±2×3×2=±12 (둘 다 말하는지 확인)
5. (x+3)²과 3(x+1)²은 둘 다 완전제곱식이야? [A] → 둘 다
3회차 (유형 2-3)
6. −3<x<1일 때 √(x²−2x+1)+√(x²+6x+9)를 간단히 하려면 어떤 차례로 해? → (x−1)², (x+3)² → √(A²)=|A| → 부호 → (1−x)+(x+3)=4

## 44. x²+□x+25가 완전제곱식이 되는 □ (101쪽)
핵심 A 가운데 항은 ± 두 가지 · B 문자까지
1회차
1. x²+□x+25가 완전제곱식이 되려면 □는? 왜 두 개야? [A] → ±10
2. x²+□+25y²에서 □에 들어갈 식은? [B] → ±10xy
2회차
3. 친구가 x²+□x+49에서 □=14라고만 했어. 뭐가 빠졌어? [A] → −14
4. 4x²+kx+9가 완전제곱식이 되는 k를 모두 구하는 과정을 말해 봐. [A] → ±12
3회차 (유형 2-1)
5. x²+Ax+9=(x+B)²이고 A, B가 양수일 때 A−B는 어떤 차례로 구해? → B=3 → A=6 → 3

## 45. a²−b² (102쪽)
핵심 A 공식 · B 항 2개, 둘 다 제곱, 빼기 · C 1=1², 순서 바꾸기, 공통인수 먼저, 끝까지
1회차
1. x²−36을 인수분해하는 과정을 말해 봐. [A] → (x+6)(x−6)
2. 이 공식은 어떤 식에서 쓸 수 있어? [B] → 항 2개, 둘 다 제곱, 빼기
3. −x²+16은 어떻게 바꿔서 인수분해해? [C] → 16−x²=(4+x)(4−x)
2회차
4. x²+9도 이 공식으로 인수분해돼? [B] → 안 됨(제곱의 합)
5. 2x²−18을 인수분해할 때 가장 먼저 할 일은? [C] → 2(x+3)(x−3)
6. 9x²−4y²을 인수분해하는 과정을 말해 봐. [A] → (3x)²−(2y)² → (3x+2y)(3x−2y)
3회차 (유형 3-3, 3-2)
7. x⁴−16을 끝까지 인수분해하려면 어떤 차례로 해? → (x²+4)(x²−4) → (x²+4)(x+2)(x−2)
8. a²(x−2)+b²(2−x)는 어떻게 시작해? → 2−x=−(x−2) → (x−2)(a+b)(a−b)

## 46. x²+(a+b)x+ab (103쪽)
핵심 A 곱=상수항, 합=x의 계수 · B 곱부터 · C 부호(상수항 양수→같은 부호, 음수→다른 부호)
1회차
1. x²+7x+12를 인수분해하는 과정을 말해 봐. [A] → (x+3)(x+4)
2. 두 수를 찾을 때 곱과 합 중 뭐부터 찾아? 왜? [B] → 곱부터(짝이 적어 나열 쉬움)
2회차
3. x²−2x−15에서 두 수의 부호는 어떻게 정해? [C] → 다른 부호, 큰 쪽 음수 → (x+3)(x−5)
4. x²−9x+14에서 두 수는 둘 다 어떤 부호야? 왜? [C] → 둘 다 음수 → (x−2)(x−7)
5. 친구가 x²+x−12를 (x+3)(x−4)로 인수분해했어. 뭐가 틀렸어? [C] → 전개하면 x²−x−12, (x−3)(x+4)
6. 🖼 x² 1개, x 3개, 1 2개 조각을 모두 써서 직사각형을 만들면 가로와 세로는? [A] → x+1, x+2 (유형 6)
3회차 (유형 4-3)
7. x²+Ax+16이 계수가 정수인 두 일차식의 곱으로 인수분해될 때 A가 될 수 있는 수는 어떤 차례로 찾아? → 곱 16 짝(음수 포함) → 합 → ±17, ±10, ±8

## 47. acx²+(ad+bc)x+bd (104쪽)
핵심 A x² 계수·상수항을 두 수의 곱으로 나눠 세로로 · B 대각선 곱의 합 · C 배치·부호
1회차
1. 2x²+7x+3을 인수분해하는 과정을 말해 봐. [A·B] → 2×3+1×1=7 → (2x+1)(x+3)
2. 합을 확인할 때 어느 방향으로 곱한 두 수를 더해? [B] → 대각선
2회차
3. 3x²−x−4를 인수분해하는 과정을 말해 봐. [A·C] → 1×(−4)+3×1=−1 → (x+1)(3x−4)
4. 2x²+x−15를 인수분해하는 과정을 말해 봐. [A·C] → 2×3+1×(−5)=1 → (2x−5)(x+3)
3회차 (유형 5-2)
5. 6x²+7x+2=(ax+b)(cx+d), 정수, a>0일 때 a+b+c+d는 어떤 차례로 구해? → (2x+1)(3x+2) → 8

## 48. 인수가 주어졌을 때 (105쪽)
핵심 A (인수)×(□)로 놓고 나머지 인수 · B x−2가 인수이면 x=2 대입하면 0
1회차
1. 2x²+Ax−6이 x−2로 나누어떨어진다는 건 무슨 뜻이야? [A] → (x−2)×(□)로 쓸 수 있다
2. 2x²+Ax−6이 x−2로 나누어떨어질 때, 2x²+Ax−6=(x−2)(□)에서 □ 안의 식은 어떻게 찾아? [A] → 2x+3 → A=−1
2회차
3. 2x²+Ax−6이 x−2로 나누어떨어질 때, 대입을 이용해서 A를 구하는 방법을 말해 봐. [B] → x=2 → 8+2A−6=0 → −1
4. x²+ax−10이 x+2로 나누어떨어질 때 a를 구하는 과정을 말해 봐. [B] → x=−2 → a=−3
3회차 (유형 5-3)
5. 12x²+ax−8이 2x+1을 인수로 가질 때 a를 구하는 두 가지 방법을 말해 봐. → (2x+1)(6x−8) 전개 a=−10 / x=−1/2 대입

## 단원 마무리 (2회차)
- 인수분해 문제를 보면 어떤 차례로 생각해? → 공통인수 → 항의 개수(2개 제곱의 차 / 3개 완전제곱식→곱과 합→대각선) → 끝까지
